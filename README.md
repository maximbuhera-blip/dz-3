# Моя візитка

Навчальний сайт-візитка, створений за допомогою HTML і CSS.

## Функція

Перемикач світлої та темної теми. Вибір зберігається в браузері після оновлення сторінки.

## Запуск

Відкрий файл `dz/index.html` у браузері.

## Файли сайту

- `dz/index.html` — структура сторінки та кнопка теми
- `dz/style.css` — оформлення і кольори тем
- `dz/script.js` — перемикання теми та збереження вибору
